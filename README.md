# Project-Assignment
Spam Classification Internship Project
Objective
Compare a traditional TF-IDF + classifier pipeline with a fine-tuned DistilBERT classifier for spam vs ham email classification.
Dataset
Download the CSV from the exact Kaggle dataset specified in the assignment:
https://www.kaggle.com/datasets/ashfakyeafi/spam-email-classification
Do not upload private or sensitive email data. Use only the assignment dataset.
Setup
Python 3.10 or 3.11 is recommended. A GPU is strongly recommended for DistilBERT; CPU training may be slow.
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```
Run
```bash
python main.py --data "path/to/dataset.csv"
```
Optional settings:
```bash
python main.py --data "path/to/dataset.csv" --epochs 2 --batch-size 8 --max-length 192 --learning-rate 2e-5
```
For a quick pipeline smoke test only (not final results):
```bash
python main.py --data "path/to/dataset.csv" --sample-limit 500 --epochs 1
```
The first DistilBERT run downloads model weights from Hugging Face and requires internet access. Ensure the license/terms of the dataset and model are followed.
Outputs
The `outputs/` directory is generated by the run and contains:
`cleaned_dataset.csv`, `class_distribution.png`
saved traditional models (`.joblib`)
DistilBERT model and tokenizer files
`model_comparison.csv`, `experiment_summary.json`
metric comparison, confusion matrices, training curves, training-time comparison plots
Method choices
Remove missing labels, empty messages, and duplicate text/label rows.
Preserve most original message text; only normalize whitespace and null bytes. This avoids deleting meaningful URLs, numbers, punctuation, or casing cues.
Split data into 70% train, 15% validation, 15% test with stratification and a fixed random seed. Stratification helps retain class proportions in each split.
Fit TF-IDF only on training data to prevent information leakage. Use unigrams and bigrams, with a vocabulary cap.
Logistic Regression is a strong linear baseline for sparse TF-IDF text features. Multinomial Naive Bayes is a standard probabilistic baseline for non-negative term-frequency features.
Fine-tune DistilBERT using a custom PyTorch loop, AdamW, a small learning rate, gradient clipping, weight decay, and validation F1 for best-checkpoint selection.
Spam is treated as the positive class (label 1) for precision, recall and F1. Confirm the label mapping printed by the script before interpreting metrics.
Important
The script infers likely text and label column names. If it selects the wrong columns, edit `find_columns()` in `main.py` to explicitly return the correct columns. Check printed label mapping and dataset preview before accepting results.
